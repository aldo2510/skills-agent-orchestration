# Agent Orchestration: Build Your AI Dream Team

Laboratorio práctico para aprender a coordinar agentes especializados de GitHub Copilot CLI.

## Qué aprenderás
- Inspeccionar agentes especializados.
- Usar un Orchestrator para delegar trabajo.
- Separar planificación, diseño, implementación y validación.
- Revisar los handoffs producidos por los agentes.

## Qué construirás
Un dashboard "Project Pulse" con HTML, CSS y JSON.

## Cómo empezar
Copia este ejercicio a tu cuenta usando **Copy Exercise**.
