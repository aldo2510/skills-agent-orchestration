# Agent Orchestration: Build Your AI Dream Team

Laboratorio práctico para aprender a coordinar agentes especializados de GitHub Copilot CLI mediante planificación, handoffs, implementación, validación, iteración y revisión humana.

## Qué aprenderás

- Entender responsabilidades y límites de agentes especializados.
- Diseñar entradas y salidas claras entre agentes.
- Delegar planificación sin delegar automáticamente todas las decisiones.
- Coordinar diseño, implementación y validación.
- Detectar pérdida de contexto entre handoffs.
- Iterar a partir de hallazgos del Validator.
- Evaluar la calidad de la orquestación, no solo el resultado final.
- Mantener revisión humana sobre decisiones y aceptación.

## Qué construirás

Un dashboard **Project Pulse** con HTML, CSS y JSON, sin backend.

## Cómo empezar

1. Haz clic en **Copy Exercise**.
2. Crea el repositorio desde la plantilla.
3. GitHub Actions iniciará el ejercicio y creará el Issue con el Step 1.
4. Sigue las instrucciones del Issue; cada entrega habilitará automáticamente el siguiente Step.

## Duración

**90-110 minutos.**

La duración depende de cuánto profundices en las comparaciones, handoffs, correcciones y discusión de resultados.

## Progresión

1. Conoce el equipo de agentes — 15-18 min.
2. Planifica con Planner — 15-18 min.
3. Orquesta diseño, desarrollo y validación — 40-45 min.
4. Revisa la calidad de la orquestación — 12-15 min.
5. Handoff final y revisión humana — 10-12 min.

## Regla del laboratorio

Los agentes ejecutan tareas especializadas; el **Orchestrator coordina**, pero no debería convertirse en un agente que hace todo.

La persona mantiene el control sobre:

- aceptación de requisitos;
- decisiones de diseño;
- evaluación del riesgo;
- revisión de evidencia;
- aceptación del resultado final.

**Los agentes proponen y ejecutan; tú decides cuándo el trabajo está realmente terminado.**
