# Agent Orchestration: Build Your AI Dream Team

Laboratorio práctico para aprender a coordinar agentes especializados de GitHub Copilot CLI.

## Qué aprenderás

- Inspeccionar agentes especializados.
- Delegar planificación.
- Coordinar diseño, implementación y validación.
- Diseñar handoffs entre agentes.
- Iterar a partir de resultados de validación.
- Mantener revisión humana sobre las decisiones.

## Qué construirás

Un dashboard Project Pulse con HTML, CSS y JSON, sin backend.

## Cómo empezar

Copia este ejercicio a tu cuenta usando Copy Exercise.

## Duración

**80-90 minutos.**

## Progresión

1. Conoce el equipo de agentes — 12-14 min.
2. Planifica con Planner — 12-14 min.
3. Orquesta diseño, desarrollo y validación — 35-38 min.
4. Revisa la calidad de la orquestación — 10-12 min.
5. Handoff final y revisión humana — 10-12 min.

## Regla del laboratorio

Los agentes ejecutan tareas especializadas; el Orchestrator mantiene contexto y coordinación; la persona mantiene el control sobre las decisiones y la aceptación del resultado.
