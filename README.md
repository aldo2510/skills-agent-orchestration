# Agent Orchestration: Build Your AI Dream Team

Laboratorio práctico guiado para aprender a coordinar agentes especializados mediante planificación, handoffs, implementación, validación, iteración y revisión humana.

## Qué aprenderás

- Entender responsabilidades y límites de agentes especializados.
- Diseñar entradas y salidas claras entre agentes.
- Delegar planificación.
- Coordinar diseño, implementación y validación.
- Detectar pérdida de contexto entre handoffs.
- Iterar a partir de hallazgos del Validator.
- Evaluar la calidad de una orquestación.
- Mantener revisión humana sobre decisiones y aceptación.

## Qué construirás

Un dashboard **Project Pulse** con HTML, CSS y JSON, sin backend.

## Cómo empezar

1. Haz clic en **Copy Exercise**.
2. Crea el repositorio desde la plantilla.
3. GitHub Actions iniciará el ejercicio y creará el Issue con el Step 1.
4. Sigue las instrucciones del Issue.
5. Cada entrega validada habilitará automáticamente el siguiente Step.

## Duración

**90-110 minutos.**

## Progresión — 10 Steps

1. Conoce el equipo de agentes — 12-14 min.
2. Planifica con Planner — 12-14 min.
3. Diseña con Designer — 10-12 min.
4. Implementa con Coder — 10-12 min.
5. Valida con Validator — 10-12 min.
6. Corrige mediante handoffs — 8-10 min.
7. Ejecuta una segunda validación — 7-9 min.
8. Genera el handoff final — 8-10 min.
9. Audita la orquestación — 8-10 min.
10. Revisión humana final — 10-12 min.

**Total orientativo: 95-115 minutos**, dependiendo de la velocidad de ejecución y revisión.

## Regla del laboratorio

Los agentes ejecutan tareas especializadas; el **Orchestrator coordina** y mantiene el contexto.

Las instrucciones están preparadas para copiar y pegar. El objetivo no es que el alumno tenga que inventar prompts, sino experimentar el flujo:

**objetivo → delegación → handoff → ejecución → validación → iteración → decisión humana.**

La persona mantiene el control sobre:

- aceptación de requisitos;
- decisiones de diseño;
- evaluación del riesgo;
- revisión de evidencia;
- aceptación del resultado final.
